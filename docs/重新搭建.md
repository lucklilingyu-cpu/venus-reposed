# 从零重新搭建（备用）

现在的网站已经在运行，平时**不需要**看这一页。只有在想另起一套新的数据库和网址时，才按下面做，大约 15 分钟。

## 第一步：建数据库（Supabase）

1. 打开 https://supabase.com ，点 **Start your project**，用 GitHub 或邮箱注册。
2. 点 **New project**：
   - **Name**：`venus-reposed`
   - **Database Password**：设一个并记下（网站用不到，只是 Supabase 要求）
   - **Region**：选 **West EU (London)**
   - 点 **Create**，等 1–2 分钟项目准备好。
3. 左侧点 **SQL Editor** → **New query**。
4. 打开仓库里的 `supabase/setup.sql`，全选复制，粘贴进去。
5. 把最后几行里的编辑码换成新的：至少 10 个字符，不要用生日或学号。
6. 点 **Run**，看到 *Success* 即可。

## 第二步：把数据库地址填进网站

1. 在 Supabase 左侧点 **Project Settings → API Keys**，或者点顶部的 **Connect**。
2. 复制两样东西：
   - **Project URL**：形如 `https://abcdefgh.supabase.co`
   - **anon / publishable key**：以 `eyJ` 或 `sb_publishable_` 开头
3. 填进仓库里的 `config.js`。
   - `editCode` 那一行：留着 = 任何人都能编辑；删掉 = 只有输入编辑码的人能编辑。
   - 只能填 anon / publishable key。**不要**填 `service_role` 或 `secret` key，它们不能出现在网页里。

## 第三步：上线（GitHub Pages）

1. 在 GitHub 上新建一个**公开**仓库，把这个文件夹里的所有文件传上去（包括 `.nojekyll`）。
2. 仓库页面点 **Settings → Pages**：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 `main`，文件夹选 `/ (root)`
   - 点 **Save**
3. 等 1–2 分钟，网址是 `https://<用户名>.github.io/<仓库名>/`。
4. 在 **Settings → Collaborators** 里点 **Add people**，邀请组员，他们就能改代码了。

## 也可以放在别的地方

整个文件夹就是一个静态网站，没有构建步骤：

- **Netlify / Cloudflare Pages**：发布目录填仓库根目录，构建命令留空。
- **注意 Netlify 免费版的额度**：每次上线都会扣额度，用完后网站会被暂停到下个月。组员经常改代码时，不建议用 Netlify 免费版。
