# 雕塑移动与丰富度

水池外围绿色地砖边界为 x = −16.7…16.7、z = −4.8…4.8。棋盘中心分布收紧到 x = −13.2…13.2、z = −2.5…2.5，保留 2.3 米余量，覆盖雕塑、底座、移动光圈与落地脉冲。极端宽深比的上传模型会自动适配展示尺寸。

生成动作序列时，动作雕塑仍沿当前骨架或 S 形轨迹按顺序排列。未使用雕塑只在剩余位置内随机分配，并给原地停留设置很高的代价；存在可交换位置时会全部移动，不占用动作雕塑的位置。

重新生成日记、视频或照片序列，会优先挑选同一姿势类别的其他雕塑；保留平台已认可的兼容姿势。若没有其他可用候选，则保留可用模型。手动指定和保存序列里的覆盖项沿用原有机制。单纯切换排布轨迹不会随机更换动作模型。

所有雕塑同时启动，在 4.5 秒内一起到位；生成时先有 0.35 秒准备，底座在 4.85 秒时统一落地。原地雕塑也同步抬升和落下。移动沿棋盘横纵方向进行，抬升高度 0.5 米，带柔光跟随环和落地脉冲。快速重复生成会取消旧的底座移动和完成计时；过期的模型请求不会覆盖新序列。系统减少动态效果时直接换位，但仍执行随机分配。

检查：`node tools/check.mjs`、`node tools/check_movement.mjs`、`node tools/check_hall_detail.mjs`。移动检查覆盖 50 次重排、姿势兼容、无重复模型、未使用雕塑全体移动、动作与手动位置、所有棋盘路径及底座光圈边界。

碎片效果：生成时，替换的作品照常碎片消失，额外随机选取 70% 保留作品也碎片消失，到位后重现同一模型。示例序列共 21 件，通常有 17 件触发碎片，另外 4 件保持可见。碎片池为 1280，支持集体爆发；普通轨迹调整不触发额外消失，减少动态效果设置会跳过碎片动画。
