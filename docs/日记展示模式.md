# 日记展示模式

Text diary 面板提供「基础版 Basic」和「豪华版 Deluxe」切换，默认豪华版。选择会保存到这台设备；存储被浏览器禁用时仍可正常切换。

- 基础版：只显示当前动作记录的雕塑。无关雕塑的模型、骨架和附属丝带整体隐藏，也不能被点击选中。生成时不播放无关雕塑的碎片效果。
- 豪华版：保留所有雕塑原来的群体移动；动作记录涉及的雕塑保持不透明，其他雕塑透明度为 60%（材质 opacity 为 0.4），不产生实心投影。

切换不重新生成记录、不替换模型、不改变顺序或移动路径。连线、2 秒顺序编号和头顶姿势名称继续用于动作记录中的雕塑。清空记录后基础版不显示序列雕塑，豪华版仍显示背景雕塑。

半透明石膏使用展厅专用材质，不修改图谱单件预览的共享材质。升起、碎片淡出和昼夜切换都保持对应透明度。

头顶姿势名称与临时编号均为纯黑文字，无背景、边框或阴影，字体沿用雕塑详情标题的 `--font-display`。

验证：`node tools/check_diary_modes.mjs`、`node tools/check_movement.mjs`、`node tools/check_sequence_guide.mjs`、`node tools/check_lighting.mjs`、`node tools/check.mjs`。
