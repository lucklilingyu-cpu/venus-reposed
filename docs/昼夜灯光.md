# 展厅昼夜灯光

顶部「夜晚 / 白天」按钮切换展厅照明。夜晚以深蓝环境光、粉蓝洗墙灯、水池和回廊灯带、拱顶灯线营造现代氛围，保留建筑与白色陶瓷雕塑。

切换采用约 2.6 秒的平滑灯光过渡，日光减弱后灯带依次亮起；水面反射、天空、玻璃和顶部工具栏同步变化。连续点击从当前照明程度反向过渡。系统启用减少动态效果时立即切换。模式保存在这台设备的 `venus.lighting` 中；禁用本地存储也可以使用。

`js/04c-lighting.js` 控制灯具、材质照明和渐变，由主渲染循环更新。新增四盏无阴影洗墙灯，沿用现有日光与门廊阴影，不新增高成本阴影贴图；稳定状态没有每帧灯光更新。图谱单件的白色工作室照明独立于展厅模式。

检查：`node tools/check.mjs`、`node tools/check_lighting.mjs`，以及浏览器昼夜切换、快速反向切换、刷新恢复和手机布局。
