# 图谱同步 · 2026-10-14

来源：https://goddess-sculpture-atlas.silkykoala4.chatgpt.site/

同步当前发布的 `data/collection-records.json`、`data/gallery-map.json`、原有及新增骨骼候选、轻量网格、缩略图和精细网格。共 118 件作品；117 件提供 GGP2 精细模型，保留源网站的平滑法线与折角。模型 92（Sagalassos 建筑）当前只有轻量版，沿用该资源。

新增 106–118 的博物馆来源、许可和署名已存入图谱记录。原有 `data/atlas-extra.json` 的姿势修正继续生效；106 已进入主目录，不再重复保存旧记录。115、116 的姿势尚未确认，只在图谱中展示，不自动进入姿势替换序列。

展厅先加载原有轻量模型；选中雕塑和打开单件图谱时加载本地 `md/<id>.bin.gz` 精细模型。其他展厅雕塑保持轻量版，避免同时加载大量精细网格。网络失败或浏览器不支持 gzip 解压时使用轻量版。精细模型无需连接源网站，因此源网站之后变动不会影响已发布展厅。

统一使用白色釉面陶瓷材质，调整白度、粗糙度和釉面反射；不使用原扫描的彩色贴图。此次没有补造缺失身体部位，也没有修改原始扫描。

以后把源站这些公开资源保存成同样目录结构，再运行：

```
python tools/build_atlas.py <下载资源目录>
node tools/check.mjs
node tools/check_atlas.mjs
```

`data/atlas-models.json` 记录每件精细网格的面数、顶点数及源站 SHA256；校验脚本同时检查压缩文件和解压后的文件，避免错配或损坏。
