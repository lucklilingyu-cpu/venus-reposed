# 双击聚焦与升起灯束

双击展厅里的雕塑或底座，镜头平滑靠近，名称与年代卡片向上浮现，同时点亮暖色长聚光灯束。手机可连续点两次同一件雕塑。单击其他雕塑、点击空处或按 Esc 关闭聚焦；生成新序列时自动清除聚焦。

雕塑移动落地后重新升起时，各自点亮淡蓝白色长灯束，随升起渐亮，升起完成后渐隐。灯束总长 40.4 米，从底座顶面向上延伸，顶端比穹顶最高点高约 16.9 米。双击聚焦与升起使用相同长度，穹顶不作为灯束的截断高度。

同时最多启用四盏升起用的实际聚光灯；所有升起雕塑都有可见灯束，材质和几何复用。实际灯光不投射阴影。中断或重新生成时清除旧灯束及灯光占用。系统设置为减少动态效果时，不播放升起灯束及卡片浮现动画。
