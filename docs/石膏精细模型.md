# 展厅石膏精细模型 · 2026-10-14

开场序列中的 20 件原有雕塑从 `D:\新建文件夹\3D model` 的 OBJ 原件重新生成高精度网格，每件最多 36 万三角面。新增的 Demeter（106）继续使用已有精细模型。完整的前后面数记录在 `data/plaster-upgrade-report.json`。

输出沿用图谱的中心化、最大边归一化坐标以及每件作品的朝向矩阵，不修改原件。模型保留平滑法线，未使用细分去虚构扫描中不存在的细节。精细网格仍是 `md/<id>.bin.gz`，同一件模型的展厅与图谱查看器共享资源。浏览器分三路渐进加载，失败时保留轻量预览。

雕塑统一采用暖白哑光石膏：粗糙度 0.87、金属度 0、清漆 0，细微程序化孔隙与漫反射变化无需 UV 或贴图。远处自动淡化颗粒，减少闪烁。昼夜灯光、模型升起与替换动画沿用同一石膏着色器。精细网格加载后刷新阴影，桌面像素比上限提升至 2。

线上网页通过相对路径读取随网站发布的模型，不直接读取访客的 D 盘。原始文件保留在本地；网页不会上传摄像头数据。

验证：`node tools/check.mjs`、`node tools/check_atlas.mjs`、`node tools/check_hall_detail.mjs`、`node tools/check_lighting.mjs`。网格清单记录打包哈希和本地原件哈希，便于核查来源。
