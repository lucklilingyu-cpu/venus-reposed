# Skeleton Video Collection

在“视频 / 照片”里新增独立视频集，原 77 张“骨骼图集”的名称、数据、图片、识别、校正和展厅交互保持原样。摄像头、雕像和其他页面行为也保留。视频集仅负责播放、拖动进度和下载准备好的骨骼视频。
