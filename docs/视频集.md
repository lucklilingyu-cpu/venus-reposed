# Skeleton Video Collection

在“视频 / 照片”里，在“骨骼图集”与其校正工具下方新增独立视频集，原 77 张“骨骼图集”的名称、数据、图片、识别、校正和展厅交互保持原样。摄像头、雕像和其他页面行为也保留。视频集仅负责播放、拖动进度和下载准备好的骨骼视频。

本集包含七条 Venus / Aphrodite、两条 Medusa 和一条 Venus / Nephthys 主题的完整分析结果，保留原有骨骼叠加和音轨。网页副本使用 H.264 / AAC、最高 1280 × 720 像素、30 fps，并把 MP4 索引前置。新增视频按原比例缩放，保留完整画面；原有九条网页文件和 D 盘原始分析结果保持原样。所有视频只有在选中后才开始加载，首页仅请求目录与按需显示的缩略图。

展示名称和下载文件名全部使用英文，不写版本；不同录像用序号区分。关联形象按 Venus / Aphrodite、Medusa 或 Venus / Nephthys 研究主题标注，并保留关联层级和来源链接。

- `Explicit goddess theme`：Bananarama 的歌曲直接命名 Venus。
- `Official styling association`：第一条 7SENSES 演出由 [SNH48 官方报道](https://www.snh48.com/html/snh/allnews/zixun/202201/5947.html) 比拟为维纳斯，但报道没有确认改编自某一件雕塑。
- `Visual comparison`：其他录像用于姿态视觉对照，不宣称已经获得官方编舞灵感来源确认。具体说明随视频显示。
- `Mythological imagery`：第八条采用 Medusa 相关石化意象的解读，见 [NME 评论](https://www.nme.com/reviews/kiss-of-life-midas-touch-review-3616351)。评论提出的视觉解读不等于官方确认的雕塑编舞来源；Midas 与 Medusa 是不同的神话人物。第九条是同曲舞蹈的视觉对照。
- `Explicit goddess lyrics; visual pose comparison`：第十条 Dreamcatcher《OOTD》的歌词提及 Venus 与 Nephthys，见 [Genie 歌曲与歌词资料](https://www.genie.co.kr/detail/songInfo?xgnm=104451090)。舞蹈用于姿态视觉对照，歌词命名并不证明编舞改编自某一件女神雕塑。

新增数据在 `data/pose-video-gallery.json`，网页视频在 `video/pose-gallery/`，缩略图在 `img/pose-video-gallery/`。独立脚本 `js/07b-pose-video-gallery.js` 不调用原照片识别或雕塑更新函数；新增 CSS 仅作用于视频集选择器。
