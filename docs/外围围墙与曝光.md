# 外围围墙与曝光

在现有 V&A 扫描模型外围独立添加四面哑光浅灰绿墙，墙高 24.4 米，平面范围为 x = ±26 米、z = ±13 米；顶部用微蓝玻璃封顶，配细金属框和玻璃分格。墙体不改动扫描模型及其材质分区，也不恢复已经移除的旧程序化博物馆。现有步行和镜头范围均在新围墙内。

白天曝光从 0.92 降至 0.70，太阳强度从 4.4 降至 1.8；同步降低环境、补光和反射。夜间曝光降至 0.68，粉蓝洗墙灯从 1000 降至 450，辉光从 0.32 降至 0.12，并提高辉光阈值。双击聚焦的实际灯光从 2000 降至 1000，保留原有长灯束和模型上方的纯文字标签。

玻璃顶不投射整片实心阴影，细框投影；外围墙体投射并接收阴影。玻璃外的天空改为柔和灰蓝，夜晚为深蓝，避免透过玻璃看到高亮白底。昼夜切换的过渡、记忆和减少动态效果设置继续有效。

墙面调整：外围墙采用纯白哑光材质，无纹理、网格、接缝或玻璃框投影。底部沿用与扫描展厅相近的灰绿色，4–14 米之间连续平滑渐变，14 米以上为纯白色。只关闭新围墙的阴影接收，围墙继续为展厅投影；玻璃顶框架保留。
