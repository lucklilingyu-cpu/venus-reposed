# 日记动作指引

生成动作记录后，等待雕塑完成移动和重建，再按记录顺序连接对应雕塑。青绿色连线带方向箭头，端点跟随雕塑实际模型的世界坐标，不连接叙事之外的雕塑。

参与记录的雕塑头顶显示姿势名称（复杂姿势同时显示手势）。顺序编号从 1 开始，显示 2 秒后隐藏；连线和姿势名称保留，便于观众继续辨认。名称随相机视角投影，位于画面外或相机后方时隐藏。

重新生成或清空记录会立即移除旧指引；切换排布后重新建立指引。单个动作只显示姿势名称和临时编号，不生成无意义的连线。减少动态效果模式下跳过移动等待，仍保留 2 秒编号。

验证：`node tools/check.mjs`、`node tools/check_movement.mjs`、`node tools/check_sequence_guide.mjs`。新检查覆盖移动/重建等待、非记录雕塑过滤、2 秒时限、旧请求失效、清空和单动作。
