# 日记动作指引

生成动作记录后，等待雕塑完成移动和重建，再按记录顺序连接对应雕塑。青绿色连线带方向箭头，端点跟随雕塑实际模型的世界坐标，不连接叙事之外的雕塑。

参与记录的雕塑头顶显示姿势名称（复杂姿势同时显示手势）。文字柔和淡入，保留到第 5 秒，再用 1 秒渐隐消失。顺序编号从 1 开始，地面连线、箭头和顺序编号统一在 2 秒内结束：前 0.22 秒淡入，一支箭头沿动作顺序前进，连线随箭头逐段展开，最后 0.6 秒渐隐后移除。基础版、豪华版及所有视图使用同一时限。名称随相机视角投影，位于画面外或相机后方时隐藏。

重新生成或清空记录会移除旧指引；切换排布后重新建立指引。单个动作只显示姿势名称和临时编号，不生成无意义的连线。减少动态效果模式下箭头静止、连线不逐段展开，仍保留淡入淡出和显示时长。

验证：`node tools/check.mjs`、`node tools/check_movement.mjs`、`node tools/check_sequence_guide.mjs`。新检查覆盖移动/重建等待、非记录雕塑过滤、2 秒时限、旧请求失效、清空和单动作。
